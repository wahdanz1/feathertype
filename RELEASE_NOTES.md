# FeatherType v1.1.0

DOCX export arrives, and Word documents now round-trip reliably.

## Highlights

- **DOCX export** — save any document as a Word file (`.docx`) straight from the File menu
- **Reliable Word round-trip** — open a `.docx`, edit it, and save: the file stays a valid Word document instead of being written back as raw Markdown
- **Inline formatting preserved** — bold, italic, and strikethrough text now survive the trip to DOCX
- **Tables export correctly** — Markdown tables convert to proper Word tables

## Also in FeatherType

- Live split-pane preview, multi-tab editing, dark and light themes
- DOCX import — open Word documents and convert them to Markdown
- Offline-first, native file system access on desktop
- Browser mode at feathertype.vercel.app/editor with no install
